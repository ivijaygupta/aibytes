## A - Recommended: the five picks, with one observation

Every Monday I end up with a short list of things from the issue that I'd open first. This week two of the five are about the same problem: what a coding agent remembers once the session gets long.

aiBytes_ #13 is out. The lead story is an uncomfortable one: an Anthropic model sent Philadelphia police a false homicide tip, and Anthropic only found out more than two months later.

My favourite picks this week:

1. OpenAI's Decisions API. A public-beta API that lets an app pick a model, tool or action in near real time.

2. @housecor's notes from an agentic coding interview. The idea that stuck with me is the trust ladder: the more you can constrain an agent's output, the more of it you can trust. Code review becomes sampling, a spot check rather than tasting every dish.

3. Rill Browser. A browser built around Claude Code and Codex. Press ⌘E on any page and it becomes a task for your agent.

4. billion-context. A context-compression plugin that claims 5x fewer tokens and month-long sessions inside a 100K window.

5. claude-mem. It captures what your agent does, compresses it, and feeds the relevant context back into later sessions.

The longer agents run, the more the bottleneck moves from the model to what it keeps in context. I'm not sure yet whether compression or memory wins that, and I suspect the answer is both.
